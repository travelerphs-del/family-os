Google API Key
지도와 장소 검색을 위해 Google API key가 필요해요.
console.cloud.google.com → APIs & Services → Credentials 에서 발급.
같은 key 에 다음 두 API 활성화 필요: Maps JavaScript API + Places API (New).
키는 이 기기 브라우저에만 저장돼요 (LocalStorage).
안전망: Cloud Console → Quotas 에서 Maps JavaScript API daily limit 100~300, Places API daily limit 100 으로 설정 + HTTP referrer 제한 권장.
`AIza` 로 시작하는 39자 키. Maps + Places 둘 다 활성화돼야 함.
