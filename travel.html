      Mapbox Access Token
      세계지도를 표시하려면 Mapbox Public Token이 필요해요.
      mapbox.com → Account → Tokens → Default public token 을 복사해 붙여넣으세요.
      토큰은 이 기기 브라우저에만 저장돼요 (LocalStorage).
      팁: Mapbox Account → Billing → Usage limits 에서 한도를 걸어두면 안전해요.
      `pk.` 로 시작하는 public token 만. secret(sk.) token 은 절대 사용하지 마세요.
